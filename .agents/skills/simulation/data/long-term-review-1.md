## PART 2 — HOW MEMORIES ARE CREATED & APPENDED (mechanism)

Two distinct writers modify entity profiles:

1. **Per-turn (Director output → `apply_state_mutations`, every round):**
   - `present_append` → **merged (appended) into `entity.present`** (physical/non_physical).
   - `eternal_consolidated` / `eternal_baseline` / `eternal_mutations` → **merged (appended) into `entity.eternal`**.
   - `vector_append` → **pushed to `entity.future`** (AI_CHARACTER + FRACTAL only; the user persona gets no per-turn futures).

2. **Per-batch (consolidation at ≥8 unconsolidated non-system messages → `forge_memory`, then `consolidate`):**
   - A single LLM call returns per-target: `vector_append` (past/future/present vectors), `present_consolidated`, `eternal_consolidated`.
   - `past` vectors → appended to `entity.past`.
   - `future` vectors → appended to `entity.future`.
   - `present` vectors → merged into `entity.present.non_physical`.
   - `present_consolidated` → **replaces** `entity.present` fields _only if the LLM returns them_.
   - `eternal_consolidated` → **merged into `entity.eternal`**.
   - Forged messages are flagged `meta.consolidated:true` and excluded from future hydration.

3. **Vector resolution (`resolve`):** a Director `vector_resolve` moves a future vector → past on completion (present in code; no strong evidence of firing in this session's data).

## PART 3 — OVERARCHING REVIEW

### A. The profile MESS — root causes (confirmed)

1. **`eternal` is not eternal.** Two code paths (`apply_state_mutations` per turn + `eternal_consolidated` per batch) MERGE new prose into `entity.eternal` via `merge_prose_into_field`, which **appends without dedup**. Result: Orion's immutable identity now says "celebrity trainer oblivious to the board" AND "corporate puppet permanently severed" AND "permanently discarded" (twice) simultaneously — direct contradictions in the same field.
2. **Truncated opening:** Orion's `eternal.non_physical` literally begins "ve gains. Operating as a celebrity trainer…" — the sentence's head is missing, a sign of a bad LLM overwrite/merge at some earlier point.
3. **`present` is never house-cleaned.** `present_consolidated` should REPLACE stale state but the LLM rarely returns it (6 forges → 0 successful replacements observed). Meanwhile per-turn appends accumulate: the profile simultaneously places Beast "by the wall of files in B7," "moving in tandem with Orion," and "standing in the penthouse doorway."
4. **Future cap is a silent information-loss mechanism.** Orion/Tartarus sit at exactly 30 futures. The oldest (arc-defining early beats) are dropped without trace; `past` (uncapped) grows only via batches, so the ratio skews: by round 23, 30 goals vs 7 memories.
5. **Duplicate vector IDs from seeding:** initial past/future vectors reuse `entity.id` as the vector id (e.g., `tartarus`, `valerius` appear as id for multiple vectors) — latent integrity bug.

### B. Prompt-pipeline verdict for narrative excellence: **B+ prose, C+ memory, C− driving**

- **Prose:** genuinely strong. Register control (himbo→raw) is the standout; the model integrates taunts/backstory; produces real lines ("Let's burn the mirrors," "A death warrant is something I actually own," "Two cages, one key"). GRRM style directive holds up; worldbuilding stays consistent across 23 rounds.
- **Memory:** the _effect_ is good (emotionally coherent pasts, thematically locked futures) but the _content_ is weak for continuity. **Facts are systematically discarded** (Bone Yard, firebombing, consortium of three names, B7, Sector 4 live only in futures or not at all). 60 rounds would leave the plot factually adrift.
- **Driving:** the AI reacts excellently but never _drives_. Every major plot advancement in rounds 14–23 came from the user's messages; the AI escalated mood but not events. The Director pass is effectively a mood-tuner, not a plot-engine.
- **Dynamics:** arc-level, the numbers track the story (Affinity climbs then withdraws; Chaos/Intensity spike at the penthouse). Round-level, they're noisy and partially decoupled from the felt register (quiet beats still push Intensity; the biggest vulnerability beats barely move Openness).

### C. Ai-isms catalog (repeat offenders)

1. **Somatic clichés:** "taste of copper" (≈8×), "chest heaves/heaving," "heart hammers against my ribs," "heat floods my chest," "spandex across my pecs," "muscles strain against the fabric," "stomach twists into a knot," "hair on my neck prickles."
2. **The 3-beat paragraph** (sensory → internal feeling → pose + pun) — every Orion paragraph is the same skeleton by round 5.
3. **The register-drop move** ("boom fades to a low rasp when serious") — used well but is now the _only_ tool for gravity.
4. **Destruction-as-emotion:** fists into walls/consoles ×3 in five rounds.
5. **Fractal future-diversity collapse:** the narrator generates ~6 distinct phrasings of "a security alarm/lockdown will trigger" across rounds 10–22; low-value, repetitive, and it feeds the recurring "impending security" motif into the plot.
6. **Verbatim profile leakage:** "Stay strong, citizens!" was quoted straight from Orion's eternal.

### D. Long-term story development — what worked

- The two-backstory interlock (rounds 11–13) is a genuine example of the pipeline _enabling_ long-form structure: backstory seeded by the user, integrated, mirrored by the AI's own reveal, sealed with a physical button (handshake).
- The imagery chain (crate → vat → cradle → mirrors → "settle the account") is consistent across 23 rounds — the hydration window (full recent history in context) is doing this work, not the memory vectors.
- Theme discipline (assets/trophies/products/toys) holds from round 2 to 23.

### E. Priority fix list

1. **Eternal-field corruption** (stop merging into eternal; cap/dedup; heal existing polluted profiles).
2. **Present-field accumulation** (force `present_consolidated` replacement, or add a decay/replace policy per turn).
3. **Memory fact-retention** (add a "facts" vector type or instruct the forger to preserve concrete entities/places/numbers; currently affect-only).
4. **Ghost image cards** (hard cap on the fire-and-forget `visualize()` chain + failure marker + non-blank fallback UI).
5. **Orphaned-turn guard** (round-14 case: if a turn dies after logging the user message, surface it / retry / roll back).
6. **Composer freeze** (reload-only recovery; intermittently the Send button never enables and input is dead).
7. **Dynamics decoupling** (round-level deltas frequently contradict the felt register; consider aligning deltas to the Director's actual scene tone).
8. **Driverlessness** (consider a periodic plot-advance directive in the Director prompt so the AI initiates, not just reacts).
9. **Devmode logs** (in-memory only — wiped on reload; that's likely the "buggy/empty" experience).
10. **Minor:** future-cap silent drop (log or archive evictions); duplicate seed vector IDs; `updated_at` never bumps on stories; POV bleed in user-persona messages.
