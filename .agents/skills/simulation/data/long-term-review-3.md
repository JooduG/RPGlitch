They bait Voss to the dead relay station Echo Point, crush his leash remote ("Not. Your. ## 5. Remediation Roadmap

1. **[P1] Watchdog — stop crying wolf.** Arm only while a turn is executing (turn_type != USER_TURN); treat no-stream silence as a heartbeat problem, not a freeze; if phase==idle, skip force-recovery entirely; log recovery as a no-op when nothing was running. Also raise the threshold to ~180s for LLM first-token latency.
2. **[P2] Future-vector eviction policy.** Never evict origin/premade vectors: keep a baseline snapshot per entity (the schema already has dynamics_baseline) and restore origin futures into a protected bucket, or evict oldest _forged_ vectors only.
3. **[P2] Profile editor data-loss footgun.** Auto-save on close, or show a confirm-discard prompt when the edit dialog closes with unsaved changes ("New Character" incident).
4. **[P3] Consolidation UX.** While forges/archive run after a turn, show a subtle "processing memory…" state instead of silently disabling the send button (E2).
5. **[P3] Log hygiene.** Deduplicate "System Online" per load; add a one-line per-turn summary to the devmode feed (round, forges, deltas) so the inline log is scannable.
6. **[P3] Voice-vocabulary drift.** Consider a per-character "verbal tics" anti-repetition rule so growl/rumble/vibration don't saturate long sessions (optional, mild).
