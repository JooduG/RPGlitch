# UI Primitives

## Overview

Design-system primitive library (`src/ui/primitives`) providing 18 Svelte 5 Runes components and a shared tooltip module action built atop `bits-ui`, `@media` transitions, `@utils` helpers, `@data` extraction, and `src/definitions` style registries. All primitives and the `tooltip` action are exposed through the [`index.js`](./index.js) barrel module.

## Interface

- [`index.js`](./index.js): Barrel module re-exporting all 18 default Svelte components (`Accordion`, `Backdrop`, `Button`, `Dialog`, `Dropdown`, `Label`, `Meter`, `Modal`, `NumberField`, `ProgressBar`, `ScrollArea`, `Shimmer`, `Slider`, `SourceField`, `StyleBadge`, `TextField`, `Toggle`, `Tooltip`) and the named `tooltip` action from [`Tooltip.svelte`](./Tooltip.svelte).
- [`Accordion.svelte`](./Accordion.svelte): Default Svelte component wrapping `bits-ui` `Collapsible`.
  - Props: `label = ""`, `open = $bindable(false)`, `default_open = false`, `disabled = false`, `class: className = ""`, `content_class = ""`, `children`.
- [`Backdrop.svelte`](./Backdrop.svelte): Default Svelte component rendering a fixed viewport backdrop container.
  - Props: `is_blurred = true`, `busy = false`, `is_pass_through = false`, `layer = "default"`, `z_index = "100"`, `variant = "default"`, `class: className = ""`, `children = null`, `actions = []`, `...rest` (spread onto outer `<div>`).
- [`Button.svelte`](./Button.svelte): Default Svelte component wrapping `bits-ui` `Button.Root`.
  - Props: `label = ""`, `children = null`, `variant = "primary"` (`"primary" | "secondary" | "danger" | "invisible" | "bare"`), `size = "md"` (`"small" | "md"`), `busy = false`, `disabled = false`, `cover = false`, `square = false`, `full_width = false`, `flank = false`, `class: className = ""`, `actions = []`, `...rest` (spread onto `Button.Root`).
  - Exported method: `focus()` calling `element?.focus()`.
- [`Dialog.svelte`](./Dialog.svelte): Default Svelte component wrapping `bits-ui` `AlertDialog`, [`Backdrop.svelte`](./Backdrop.svelte), and [`Button.svelte`](./Button.svelte).
  - Props: `title = "System Message"`, `message = ""`, `type = "alert"` (`"alert" | "confirm"`), `open = $bindable(false)`, `busy = false`, `confirm_label = "Confirm"`, `ok_label = "OK"`, `input_value = $bindable("")`, `show_input = false`, `input_placeholder = ""`, `on_confirm = () => {}`, `on_cancel = () => {}`.
- [`Dropdown.svelte`](./Dropdown.svelte): Default Svelte component wrapping `bits-ui` `Select`.
  - Props: `value = $bindable()`, `items = []` (`{ value, label, region?, tag?, disabled?, tooltip?, portrait? }`), `label = "Select Option"`, `id = undefined`, `disabled = false`, `uppercase = true`, `matchWidth = false`, `dropdownWidth = undefined`, `dropdownHeight = undefined`, `rows = 8`, `align = "start"`, `variant = "default"` (`"default" | "bare"`), `class: className = ""`, `trigger_style = ""`, `trigger_content = undefined` (snippet receiving `{ selected_item, label }`), `onchange = undefined`.
- [`Label.svelte`](./Label.svelte): Default Svelte component wrapping `bits-ui` `Label.Root`.
  - Props: `class: className = ""`, `disabled = false`, `children`, `onclick`, `...rest` (spread onto `Label.Root`).
- [`Meter.svelte`](./Meter.svelte): Default Svelte component wrapping `bits-ui` `Meter.Root`, [`Button.svelte`](./Button.svelte), [`Label.svelte`](./Label.svelte), and `tooltip`.
  - Props: `profile_state` (`is_editing`, `char`, `set_field_value(path, value)`), `dynamic` (`{ source, key, label, desc }`).
- [`Modal.svelte`](./Modal.svelte): Default Svelte component wrapping `bits-ui` `Dialog` (`Root`, `Portal`, `Overlay`, `Content`) and [`Backdrop.svelte`](./Backdrop.svelte).
  - Props: `busy = null`, `blur = true`, `is_pass_through = false`, `open = $bindable(true)`, `variant = "standard"` (`"standard" | "profile" | "bare" | "lightbox" | "preview" | "mini"`), `z_index = "200"`, `class: className = ""`, `on_close = () => {}`, `children = null`, `actions = []`, `...rest` (spread onto `Dialog.Content`).
- [`NumberField.svelte`](./NumberField.svelte): Default Svelte component rendering `<input type="number">`.
  - Props: `value = $bindable(null)`, `placeholder = ""`, `disabled = false`, `readonly = false`, `id`, `class: className = ""`, `oninput`, `onclick`, `onkeydown`, `actions = []`, `signature_color = "#475569"`, `style = ""`, `...rest` (spread onto `<input>`).
- [`ProgressBar.svelte`](./ProgressBar.svelte): Default Svelte component wrapping `bits-ui` `Progress.Root` and [`Label.svelte`](./Label.svelte).
  - Props: `value = 0` (`number | null`; `null` = indeterminate), `max = 100`, `min = 0`, `label = ""`, `value_label = ""`, `variant = "full"` (`"thin" | "full"`), `class: className = ""`, `style = ""`.
- [`ScrollArea.svelte`](./ScrollArea.svelte): Default Svelte component wrapping `bits-ui` `ScrollArea` (`Root`, `Viewport`, `Scrollbar`, `Thumb`, `Corner`).
  - Props: `children`, `class: className = ""`, `style = ""`, `orientation = "vertical"` (`"vertical" | "horizontal"`), `...rest` (spread onto `ScrollArea.Root`).
- [`Shimmer.svelte`](./Shimmer.svelte): Default Svelte component rendering a decorative loading sweep overlay.
  - Props: `color = "var(--color-electric-cyan)"`, `class: className = ""`.
- [`Slider.svelte`](./Slider.svelte): Default Svelte component wrapping `bits-ui` `Slider` (`Root`, `Thumb`) and [`Label.svelte`](./Label.svelte).
  - Props: `value = $bindable(1.0)`, `min = 0`, `max = 2.0`, `step = 0.1`, `disabled = false`, `busy = false`, `label = ""`, `neutral = null`, `format = (v) => (step < 0.1 ? Number(v).toFixed(2) : Number(v).toFixed(1))`, `actions = []`, `class: className = ""`, `style = ""`, `onchange = undefined`, `horizontal = false`, `disabled_label = "DISABLED"`, `show_value_tooltip = false`, `...rest` (spread onto `Slider.Root`).
- [`SourceField.svelte`](./SourceField.svelte): Default Svelte component wrapping [`TextField.svelte`](./TextField.svelte) and [`Button.svelte`](./Button.svelte) for URL, file drop/paste/browse, and PNG character card import.
  - Props: `value = $bindable("")`, `image_data = $bindable(null)`, `type = "character"`, `mode = "import"` (`"import" | "image"`), `disabled = false`, `busy = false`, `is_edit = true`, `placeholder = "Paste a URL, drop a .json / .png card or image, or type source text..."`, `size = "md"`, `field_class = "min-h-52"`, `signature_color = "#475569"`, `header_actions = null`, `status = null`, `oninput = undefined`, `onfocus = undefined`, `on_source = () => {}` (payloads: `{ kind: "image", data_url, url } | { kind: "image", url, name } | { kind: "image", data_url, name } | { kind: "url", url, chars } | { kind: "file", name, chars? } | { kind: "error", message }`), `...rest` (spread onto `TextField`).
- [`StyleBadge.svelte`](./StyleBadge.svelte): Default Svelte component rendering narrative and/or visual style badges resolved from `NARRATIVE_STYLES` and `VISUAL_STYLES`.
  - Props: `entity = undefined`, `class: className = "flex w-full justify-center gap-tight"`, `layout = "default"` (`"storymode" | "prologue" | "profile" | "default"`), `which = "both"` (`"both" | "narrative" | "visual"`), `tooltip: tooltip_text = undefined`.
- [`TextField.svelte`](./TextField.svelte): Default Svelte component with edit `<textarea>` (`history_stack` undo/redo) and view `parse_markdown` rendering via [`ScrollArea.svelte`](./ScrollArea.svelte) and [`Shimmer.svelte`](./Shimmer.svelte).
  - Props: `value = $bindable("")`, `placeholder = "Enter text..."`, `sync_id = null`, `is_edit = false`, `busy = false`, `disabled = false`, `active = false`, `weight = 0`, `always_expanded = false`, `collapsed = false`, `variant = "default"` (`"default" | "bare"`), `signature_color = "#475569"`, `size = "sm"` (`"xs" | "sm" | "md"`), `class: className = ""`, `style = ""`, `header_actions = null`, `status = null`, `inline_snippet = null`, `actions = []`, `oninput = undefined`, `onfocus = undefined`, `onblur = undefined`, `onheaderclick = undefined`, `...rest` (spread onto edit `<textarea>` or view `<div role="textbox">`).
- [`Toggle.svelte`](./Toggle.svelte): Default Svelte component wrapping `bits-ui` `Switch.Root` / `Switch.Thumb` and [`Label.svelte`](./Label.svelte).
  - Props: `value = $bindable(false)`, `label = ""`, `size = "md"` (`"md" | "small"`), `disabled = false`, `busy = false`, `always_signature = false`, `actions = []`, `class: className = ""`, `style = ""`, `onchange = undefined`, `...rest` (spread onto `Switch.Root`).
- [`Tooltip.svelte`](./Tooltip.svelte): Global `bits-ui` `Tooltip` renderer (no `$props()`) and `<script module>` exports:
  - `tooltip_state`: Exported `$state({ text: null, target: null, active: false })`.
  - `show_tooltip(target, text)`: Exported function scheduling tooltip activation.
  - `hide_tooltip()`: Exported function cancelling pending activation and clearing tooltip state.
  - `tooltip(node, text)`: Exported Svelte action (re-exported by [`index.js`](./index.js)) accepting `string | { text: string } | null` and returning `{ update(new_text), destroy() }`.

## Invariants

- [`Accordion.svelte`](./Accordion.svelte): `Collapsible.Content` sets `forceMount`, keeping `children` mounted and animating height via `grid-rows-[1fr]` / `grid-rows-[0fr]` (`overflow-hidden`) driven by `open`.
- [`Backdrop.svelte`](./Backdrop.svelte): `computed_z_index` maps `layer` deterministically (`"console" -> "40"`, `"cardhand" -> "50"`, `"image" -> "600"`, `"max" -> "var(--z-index-max)"`, fallback `z_index`); `className === "profile"` sets `p-0` and switches `backdrop_transition` to a 0ms no-op `profile_transition`; `is_pass_through` disables outer pointer events while enabling `*:pointer-events-auto` on `.contents` children; `busy` applies `pointer-events-none cursor-wait`; `variant === "mini"` sets `data-backdrop="mini"`.
- [`Button.svelte`](./Button.svelte): `is_flank` activates on `flank` or `"flank"` in `className`; `variant === "bare"` suppresses base styling, sizing, padding, transitions, `cover`, `square`, `full_width`, and `is_flank` classes; `cover` enforces `absolute inset-0 z-10 h-full min-h-0 w-full`; `Button.Root` sets `type="button"`, `disabled={is_disabled || busy}`, `aria-busy={busy}`, and `aria-disabled={is_disabled || busy}` before `{...rest}`.
- [`Dialog.svelte`](./Dialog.svelte): Single footer `AlertDialog.Action` derives `{ variant: "danger", label: confirm_label }` when `type === "confirm"` else `{ variant: "primary", label: ok_label }`; `handle_confirm` and `handle_cancel` early-return when `busy` is truthy and otherwise close `open = false`; `AlertDialog.Root` sets `preventScroll={false}`, `AlertDialog.Overlay` and `AlertDialog.Content` set `forceMount`, and `contentProps` is passed as `{contentProps}` on the dialog content `<div>` over `Backdrop` (`layer="max"`, `variant="mini"`).
- [`Dropdown.svelte`](./Dropdown.svelte): `Select.Root` uses `type="single"` with unique `item.value` keys in `{#each items as item (item.value)}`; `selected_item` resolves by `items.find((item) => item.value === value)`; `computed_height` defaults to `min(70dvh, calc(rows * 3.25rem))` and menu width resolves `dropdownWidth` else `matchWidth ? w-(--bits-select-anchor-width) : w-[calc(var(--bits-select-anchor-width)+3.5rem)]`; item sub-labels prefer `region || tag`.
- [`Label.svelte`](./Label.svelte): Custom click forwarding executes only when `rest.for` resolves to a `<button>` element whose `role` attribute is not `"switch"`.
- [`Meter.svelte`](./Meter.svelte): `value` reads `Number(profile_state?.char?.[dynamic?.source]?.[dynamic?.key])` inside `try/catch` defaulting to `0`; `percentage` and all edits clamp to `[0, 100]` (`clamp(..., 0, 100)`); mutations guard on `profile_state?.char?.[dynamic.source]` (`handle_input` skips `NaN`); edit controls mount only when `profile_state.is_editing` is truthy.
- [`Modal.svelte`](./Modal.svelte): `is_busy` defaults to `false` when `busy === null`; `Dialog.Root` uses one-way `open` with `preventScroll={false}` and invokes `on_close()` in `onOpenChange` when `!v`; `Dialog.Overlay` and `Dialog.Content` use `forceMount` gated on `active_open` (`$derived(open)`) and `Dialog.Content` calls `e.preventDefault()` on `onInteractOutside` and `onOpenAutoFocus`; `variant === "profile"` skips forwarding `pointerdown` to `overlayProps`, skips `Backdrop` `onclick`, omits glassmorphic card classes (also omitted for `"bare"`), and sets `overlay_in` duration to `0`; `variant === "lightbox"` uses `w-[clamp(20rem,95vw,80rem)] max-w-[95vw]` and bypasses `e.stopPropagation()`; `Backdrop` carries `data-modal-backdrop={variant}` and content carries `data-modal-variant={variant}`.
- [`NumberField.svelte`](./NumberField.svelte): Always renders `<input type="number">` with hidden spin buttons, prepends `--color-dev-accent: {signature_color}` before `style`, and switches cursor/text classes on `readonly`.
- [`ProgressBar.svelte`](./ProgressBar.svelte): `is_indeterminate` is strictly `value === null`; `clamped_pct` is `0` when indeterminate or clamped to `[0, 100]`; `label_id` from `useId()` links `Label.id` to `Progress.Root` `aria-labelledby` only when `label` is truthy; `aria-valuetext` resolves to `value_label || (is_indeterminate ? undefined : "${Math.round(clamped_pct)}%")`; `variant === "thin"` renders an `h-px` track instead of `h-2.5 rounded-full`.
- [`ScrollArea.svelte`](./ScrollArea.svelte): `ScrollArea.Root` wraps `ScrollArea.Viewport`, a single `ScrollArea.Scrollbar` bound to `orientation`, `ScrollArea.Thumb`, and `ScrollArea.Corner`.
- [`Shimmer.svelte`](./Shimmer.svelte): Strictly decorative (`pointer-events-none`, `aria-hidden="true"`, `overflow-hidden rounded-[inherit] opacity-20`) with `--shimmer-color` bound to `color`.
- [`Slider.svelte`](./Slider.svelte): `center_val` defaults to `neutral ?? (min + max) / 2` and `fill_start_css` / `fill_end_css` align track fills to the 16px (`w-4`) thumb center; `test_id` (`${label}-slider` or `"generic-slider"`) links `data-testid`, `Label` `for`, and `Slider.Root` `id`; `Slider.Root` is fixed to `type="single"`, `Slider.Thumb` `index={0}`, and `disabled={is_disabled || busy}`; tooltip activation is gated on `show_value_tooltip` and ignores descendant `mouseover`/`mouseout` via `e.currentTarget.contains(e.relatedTarget)`.
- [`SourceField.svelte`](./SourceField.svelte): `dropzone_disabled` (`is_fetching || disabled`) locks drop, browse, fetch, and `TextField` (`busy={busy || is_fetching}`); URL detection uses `/^https?:\/\//i` and image URL detection uses `/\.(png|jpe?g|webp|gif|avif|svg)([?#].*)?$/i`; `fetch_url` prevents empty or overlapping fetches and always clears `is_fetching` in `finally`; `process_file` routes `mode === "image"` through `image_file_to_data_url`, loads `.json` files via `file.text()`, and sets `image_data` for non-`.json` import files (also running `extract_card_from_png` on `.png`); clipboard files override text on paste, and pasted URLs auto-fetch only in `"image"` mode or when `value.trim()` is empty.
- [`StyleBadge.svelte`](./StyleBadge.svelte): `style_details` ignores falsy or `"default"` `narrative_style` and `vstyle_details` ignores falsy, `"none"`, or `"default"` `visual_style`; `signature_color` resolves via `get_signature_color(entity, "var(--color-gunmetal)")` and sets `--signature-color` inline only for `"storymode"` or `"profile"`; unset fallback labels render only in `"profile"` layout; layout sizing/overlay/tooltip behavior varies across `"storymode"`, `"prologue"`, `"profile"`, and `"default"`.
- [`TextField.svelte`](./TextField.svelte): `is_disabled` (`disabled || busy`) disables edit `<textarea>` and Undo/Redo buttons and short-circuits `handle_focus`; `is_sync_focused` requires truthy `sync_id` with `sync_focus_counts[sync_id] > 0`; `is_expanded` gates the header strip and ignores internal focus transfers via `root.contains(e.relatedTarget)`; `history_stack` initializes at `[value]`, caps at 50 entries via `shift()`, slices forward history on edit, and supports Ctrl/Cmd+Z undo and Ctrl/Cmd+Shift+Z / Ctrl/Cmd+Y redo; `variant === "bare"` hides `<header>` and strips container chrome; `collapsed` unmounts the body; view mode parses tokens with `parse_markdown(value)`.
- [`Toggle.svelte`](./Toggle.svelte): `test_id` (`${label}-toggle` when `label` is truthy) links `Switch.Root` `id`, `data-testid`, and `Label` `for`; `is_disabled || busy` disables `Switch.Root` and `Label` while exposing `aria-busy={busy}`; `always_signature` keeps the signature track background even when unchecked; `size === "small"` selects `h-4 w-7` / `size-3` vs `h-6 w-10` / `size-4`.
- [`Tooltip.svelte`](./Tooltip.svelte): `show_tooltip` no-ops on falsy `text` and invokes `hide_tooltip()` first so at most one 400ms timer is pending globally; `hide_tooltip` clears the timer synchronously and resets `tooltip_state` inside `setTimeout(..., 0)` to avoid `state_unsafe_mutation`; `tooltip` resolves text from `text?.text ?? text`, `aria-label`, or `title` and ignores internal descendant hover transitions via `node.contains(e.relatedTarget)`; `Tooltip.Provider` sets `delayDuration={0}` and `Tooltip.Content` mounts only when both `tooltip_state.target` and `tooltip_state.text` are truthy.

## Side Effects

- [`Accordion.svelte`](./Accordion.svelte): `bits-ui` `Collapsible.Root` manages ARIA attributes, keyboard/click toggling, and two-way mutations of `open`.
- [`Backdrop.svelte`](./Backdrop.svelte): Runs `fade` (150ms) or `profile_transition` (0ms) and executes `use:use_actions={actions}` on the outer `<div>`.
- [`Button.svelte`](./Button.svelte): `$effect` runs and cleans up `actions` on the bound `HTMLButtonElement`; `focus()` focuses the DOM button; `bits-ui` `Button.Root` attaches button attributes and `bind:ref`.
- [`Dialog.svelte`](./Dialog.svelte): Attaches a global `svelte:window` `onkeydown` listener (confirming on unshifted `Enter` outside `TEXTAREA`/`BUTTON`/`INPUT`/`isContentEditable`), portals DOM via `bits-ui` `AlertDialog.Portal`, reads `--duration-standard` / `--duration-fast` via `resolve_ms`, runs `overlay_in` / `overlay_out`, mutates `open = false`, and invokes `on_confirm()` / `on_cancel()`.
- [`Dropdown.svelte`](./Dropdown.svelte): Portals menu content via `bits-ui` `Select.Portal`, runs Svelte `scale` transition, mutates bound `value`, invokes `onchange?.(val)`, and attaches `tooltip` actions to item labels when `item.tooltip` is set.
- [`Label.svelte`](./Label.svelte): Queries `document.getElementById(rest.for)`, calls `e.preventDefault()`, schedules `requestAnimationFrame`, dispatches synthetic `PointerEvent("pointerdown")` and `target.click()` for non-switch `<button>` targets, and invokes `onclick?.(e)`.
- [`Meter.svelte`](./Meter.svelte): Calls `profile_state.set_field_value(`${dynamic.source}.${dynamic.key}`, clamped)` on button or number-input mutations and attaches `use:tooltip={dynamic.desc}`.
- [`Modal.svelte`](./Modal.svelte): `$effect` calls `on_close()` whenever `!open` (including mount if `open` is `false`); portals overlay/backdrop/content via `bits-ui` `Dialog.Portal`; prevents `Dialog.Content` outside-interaction dismissal and open auto-focus; calls `e.stopPropagation()` on non-lightbox content clicks; runs `use:use_actions={actions}` and `overlay_in` / `overlay_out`.
- [`NumberField.svelte`](./NumberField.svelte): Executes `use:use_actions={actions}` on `<input>` and forwards `bind:value`, `oninput`, `onclick`, and `onkeydown`.
- [`ProgressBar.svelte`](./ProgressBar.svelte): `$effect` drives `pct_tween.set(clamped_pct)` (`0ms` if `motion.is_reduced` else `300ms` `quartOut`); indeterminate mode runs infinite CSS keyframe animation.
- [`ScrollArea.svelte`](./ScrollArea.svelte): Delegates DOM scrolling and scrollbar management to `bits-ui` `ScrollArea`.
- [`Shimmer.svelte`](./Shimmer.svelte): Runs infinite CSS keyframe `background-position` sweep on `[data-shimmer-sweep]`.
- [`Slider.svelte`](./Slider.svelte): Mutates bound `value` and synthesizes a detached `<input type="range">` `change` event for `onchange`; `$effect` moves `tooltip_el` to `document.body` (and removes on cleanup) and reads `thumb_el.getBoundingClientRect()` to update `tooltip_pos`; registers `<svelte:window onpointerup>` and `use:use_actions={actions}`.
- [`SourceField.svelte`](./SourceField.svelte): `$effect` clears `fetched_from` when `value !== fetched_text`; executes `fetch_web(...)` network requests; reads and validates files via `validate_image`, `blob_to_data_url`, `file.text()`, `file.arrayBuffer()`, and `extract_card_from_png`; logs errors via `console.error`; opens an imperative `<input type="file">` picker; intercepts clipboard paste and drag/drop events with `e.preventDefault()`; emits payloads via `on_source(...)`.
- [`StyleBadge.svelte`](./StyleBadge.svelte): Attaches `use:tooltip` actions to badge elements and renders `<img>` elements for `dportrait` / `vportrait` URLs.
- [`TextField.svelte`](./TextField.svelte): Increments/decrements module-level `sync_focus_counts[sync_id]` on focus, blur, and `onDestroy`; `$effect` updates `history_stack` / `history_index` and schedules `setTimeout(..., 10)` checking `document.activeElement?.tagName` to reset `is_focused`; `undo()` / `redo()` mutate `value`, emit synthetic `oninput({ target: { value } })`, and schedule `setTimeout(..., 0)`; attaches `use:use_actions`, `use:auto_resize`, and `tooltip` actions.
- [`Toggle.svelte`](./Toggle.svelte): Mutates bound `value` via `bits-ui` `Switch.Root`, dispatches `new Event("change")` to `onchange`, and runs `use:use_actions={actions}`.
- [`Tooltip.svelte`](./Tooltip.svelte): Mutates module-level `tooltip_state` via `window.setTimeout` (400ms show delay) / `window.clearTimeout` and `setTimeout(..., 0)` (hide); `tooltip` action attaches/removes `mouseover`, `mouseout`, `focusin`, and `focusout` DOM listeners, moves native `title` into `dataset.tooltipTitle` while active, and portals tooltip UI via `bits-ui` `Tooltip.Portal`.
