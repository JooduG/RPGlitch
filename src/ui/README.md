# Domain UI & Controllers

## Overview

Application presentation layer (`src/ui`) implementing the Storyboard deck-selection workspace, Storymode narrative feed, Console composer and library drawer, Entity Profile editor with auxiliary wings, Relational Graph, Context Menu, Image Preview/Candidate Picker, and Svelte 5 reactive UI controllers. Built atop `@engine`, `@data`, `@media`, `@utils`, `@config`, `bits-ui`, `markdown-it`, and the child primitive package in [UI Primitives](./primitives/README.md).

- [`Storyboard.svelte`](./Storyboard.svelte): `deck_geometry` clamps `left` and `top` to `>= 0`; `claimed_entity_lock` compares non-null `String(e.id)` against a `SvelteSet`; `StoryboardController.shuffle()` skips if `app.simulation.loading`, excludes `pick_ai.id` from `available_users` when possible, and falls back to synchronous commit when reduced motion or missing slot DOM geometry prevents card flight; `StoryboardController.begin()` requires all three slots and aborts on claimed entities; `install_begin_flight_effect()` fires only when `app.begin_story_pending`, a prologue entry, `!storyboard.begin_flight_started`, and non-empty streamed `displayText` align; `execute_entity_import()` requires non-empty text plus at least one entity type flag and routes `"rpglitch"` native JSON (`run_sorter: false`), other card formats, and raw text (`run_sorter: true`); `card_step` clamps to `[1.8, 3.2]` and `get_unavailable_reason` blocks claimed or already-selected slot entities.
